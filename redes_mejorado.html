Introducción

Las redes de computadoras son sistemas que permiten la conexión entre diferentes dispositivos como computadoras, celulares y servidores. Gracias a ellas se puede compartir información, recursos y servicios a nivel local o mundial. Hoy en día son fundamentales para el internet, redes sociales, educación y trabajo.

Modelo OSI y TCP/IP

El modelo OSI divide la comunicación en 7 capas: Física, Enlace de datos, Red, Transporte, Sesión, Presentación y Aplicación. Cada capa cumple una función específica en la transmisión de datos.

El modelo TCP/IP tiene 4 capas: Acceso a la red, Internet, Transporte y Aplicación. Es el modelo que realmente se usa en internet.

Protocolos

Los protocolos son reglas que permiten la comunicación entre dispositivos en una red.

  • HTTP: navegación web
  • FTP: transferencia de archivos
  • TCP: transmisión confiable
  • IP: direccionamiento de dispositivos

Topologías

Las topologías indican la forma en que se conectan los dispositivos:

  • Estrella: todos conectados a un punto central
  • Bus: un solo cable principal
  • Anillo: conexión circular
  • Malla: todos conectados entre sí

Software de Red y Simuladores

El software de red permite configurar, monitorear y administrar redes.

Packet Tracer es un simulador que permite crear redes virtuales para practicar sin usar equipos reales. Es muy usado en educación.

Dispositivos de Red

  • Router: conecta redes diferentes
  • Switch: conecta dispositivos en una red
  • Hub: distribuye señal
  • PC: equipo final del usuario

Código de colores (Cableado UTP)

El cable UTP usa colores para organizar los pares:

  • Blanco/Verde
