Introducción

Las redes de computadoras son sistemas que permiten la interconexión de múltiples dispositivos con el fin de compartir información, recursos y servicios. Estas redes pueden ser pequeñas como una red doméstica o muy grandes como el internet.

Gracias a las redes, hoy es posible enviar mensajes, realizar videollamadas, acceder a información en tiempo real y trabajar de forma colaborativa desde cualquier lugar del mundo.

Modelo OSI y TCP/IP

El modelo OSI es un estándar que divide la comunicación en 7 capas, permitiendo entender cómo viajan los datos desde un dispositivo a otro. Cada capa tiene una función específica, desde la transmisión física hasta la interacción con el usuario.

El modelo TCP/IP, por otro lado, es el que se utiliza en la práctica en internet y simplifica el modelo OSI en 4 capas.

Protocolos

Los protocolos son reglas que permiten que los dispositivos se comuniquen correctamente. Sin ellos, la comunicación sería imposible.

Algunos protocolos importantes son HTTP para páginas web, FTP para transferencia de archivos, TCP para asegurar que los datos lleguen correctamente e IP para identificar cada dispositivo.

Topologías

Las topologías de red determinan la forma en que los dispositivos están conectados entre sí. Cada tipo tiene ventajas y desventajas dependiendo del uso.

  • Estrella: fácil de administrar
  • Bus: económico
  • Anillo: organizado
  • Malla: muy segura

Software de Red y Simuladores

El software de red permite configurar dispositivos, monitorear el tráfico y administrar conexiones.

Los simuladores como Packet Tracer son herramientas educativas que ayudan a aprender redes sin necesidad de hardware físico.

Dispositivos de Red

Los dispositivos de red son esenciales para el funcionamiento de una red.

  • Router: conecta redes distintas
  • Switch: conecta dispositivos dentro de una red
  • Hub: distribuye señal
  • PC: usuario final

Código de colores (Cableado UTP)

El cable UTP utiliza un código de colores para organizar los cables internos, permitiendo una correcta transmisión de datos.

Existen dos estándares principales: T568A y T568B.
